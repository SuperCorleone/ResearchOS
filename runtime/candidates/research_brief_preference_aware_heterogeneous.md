## Scores | Dimension | Score (0-3) | |---|---| | significance | 3 | | novelty | 2 | | differentiation | 3 | | feasibility | 2 | | falsifiability | 3 | | **total** | **13 / 15** | ## Innovation Claim - **Problem gap**: Existing methods fail because they adapt multi-agent LLM workflows with generic routing or replanning heuristics that do not explicitly model heterogeneous user requirements combining hard thresholds (e.g., cost/latency ceilings) and optimization goals, and therefore make weaker decisions under uncertainty. - **Our delta**: We propose a preference-aware MAPE-K adaptation controller that represents threshold and optimization goals explicitly and uses Bayesian model averaging over candidate workflow models to choose whether and how to adapt multi-agent LLM workflows. - **Why it matters**: Which improves task success and reduces unnecessary re-planning under uncertain workflow performance and mixed user preference constraints. ## Falsification Design - **Hypothesis**: A preference-aware MAPE-K controller with Bayesian model averaging will achieve higher constraint-satisfying task success and lower unnecessary replanning than a non-BMA adaptive workflow baseline on multi-agent LLM tasks with mixed threshold and optimization goals. - **Baseline**: A standard MAPE-K or heuristic adaptive workflow controller that selects a single best workflow model (no Bayesian model averaging) and applies replanning when predicted utility drops below a threshold. - **Metric**: Primary: constraint-satisfying task success rate (tasks completed while meeting latency/cost thresholds).
